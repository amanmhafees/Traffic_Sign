# 2️⃣ CNN ARCHITECTURE DETAILS (LAYERS)

### 🔹 Backbone: ResNet-18

ResNet-18 consists of:

| Stage           | Layers                             |
| --------------- | ---------------------------------- |
| Input           | 224 × 224 × 3                      |
| Conv1           | 7×7 Conv, 64 filters, stride 2     |
| MaxPool         | 3×3, stride 2                      |
| Block 1         | 2 × Residual blocks (64 channels)  |
| Block 2         | 2 × Residual blocks (128 channels) |
| Block 3         | 2 × Residual blocks (256 channels) |
| Block 4         | 2 × Residual blocks (512 channels) |
| Global Avg Pool | 512 → 1                            |
| Fully Connected | **512 → N classes**                |

# 7️⃣ WHY SPEED LIMIT vs LOAD LIMIT CONFUSION HAPPENS

This is a **classic vision problem**, not your fault.

### Both signs contain:

* Numbers
* Circular borders
* Similar contrast

### Key difference (CNN is missing):

* **LOAD LIMIT** → number + “t” / weight symbol
* **SPEED LIMIT** → plain number only

### Why CNN fails:

* Crops are too tight
* Symbol detail is lost
* Dataset imbalance
* Too few load-limit examples

📌 Solution (later):

* Slightly looser crop
* Ensure load-limit symbols are visible
* Add **class-specific hard negatives**
